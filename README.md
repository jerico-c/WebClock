# WebClock App

## Overview
The WebClock App is a simple web-based clock application that displays the current time and date. It is designed to be lightweight and easy to use, providing users with a clear view of the current time in a visually appealing format.

## Features
- Displays the current time in hours, minutes, and seconds.
- Shows the current date in a user-friendly format.
- Responsive design that works on various screen sizes.
- Supports multiple languages and locales.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Moment.js (for date and time manipulation)

## Installation
To run the WebClock App locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/jerico-c/WebClock.git
   ```

2. Navigate to the project directory:
   ```bash
   cd WebClock
   ```

3. Open the `index.html` file in your web browser:
   ```bash
   open index.html
   ```

## Usage
- Upon opening the application, the current time and date will be displayed.
- The time updates every second to reflect the current time accurately.

## Customization
You can customize the appearance and functionality of the WebClock App by modifying the following files:

- **index.html**: The main HTML file where the structure of the app is defined.
- **styles.css**: The CSS file for styling the clock and date display.
- **bundle.js**: The JavaScript file that handles the logic for updating the time and date.
